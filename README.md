# Zotero 分类去重

适用于 Zotero 10.0 桌面版。下载安装同目录的 `collection-cleaner.xpi`：在 Zotero 中打开“工具 → 插件”，点击齿轮菜单并选择“从文件安装插件”。

在“工具 → 分类去重…”输入分类的完整名称（区分大小写），检查弹窗里的完整条目列表，确认后执行；取消或关闭窗口不做修改。会搜索个人文献库及群组文献库；若名称不唯一则拒绝执行。

只处理同时直接属于目标分类和其任意层级子分类的条目。仅移除目标分类的归属，保留子分类归属、文献和附件；不会处理回收站中的分类或条目。群组文献库必须有编辑权限。支持在 Zotero 10 中通过“编辑 → 撤销”一次撤销本次操作。建议先备份数据；操作会随 Zotero 正常同步。

如需重新打包：在本目录运行 `zip -r collection-cleaner.xpi manifest.json bootstrap.js content`。

插件清单中的更新地址为占位地址，插件不会自动更新；新版本需手动安装。
